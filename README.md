  # Standart Contabilidade

##  Descrição

O **Standart Contabilidade** é um projeto de website desenvolvido para uma empresa de contabilidade, com o objetivo de apresentar seus serviços e facilitar o acesso dos clientes às informações da empresa. O projeto utiliza um wireframe criado no Figma para estruturar a interface e organizar os elementos de navegação.

##  Principais funcionalidades

- **Apresentação da empresa:** exibição de informações institucionais sobre a empresa de contabilidade.
- **Apresentação dos serviços:** organização dos serviços contábeis oferecidos aos clientes.
- **Navegação intuitiva:** estruturação das páginas para facilitar a navegação dos usuários.
- **Contato:** disponibilização de informações e meios de comunicação com a empresa.
- **Interface organizada:** planejamento visual das páginas para proporcionar uma experiência simples e acessível aos usuários.
